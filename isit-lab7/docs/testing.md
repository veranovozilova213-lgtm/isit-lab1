# Результаты тестирования API

| № | Запрос | Ожидаемый код | Получен код | Комментарий |
|---|---|---|---|---|
| 1 | GET /api/orders | 200 | 200 | Массив заказов |
| 2 | GET /api/orders/1 | 200 | 200 | Объект заказа |
| 3 | GET /api/orders/999 | 404 | 404 | Ошибка: заказ не найден |
| 4 | POST /api/orders (корректно) | 201 | 201 | Заголовок Location присутствует |
| 5 | POST /api/orders (без title) | 422 | 422 | Ошибка валидации |
| 6 | GET /api/couriers | 200 | 200 | Список курьеров |
| 7 | GET /api/customers | 200 | 200 | Список клиентов |
