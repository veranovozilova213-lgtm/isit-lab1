# **Отчет по лабораторной работе №1**



### **Задание** 



**Вариант 12. Система управления доставками**



Система предназначена для управления доставкой заказов клиентам. Необходимо учитывать заказы, клиентов, адреса доставки, курьеров и статусы заказов. 
Оператор должен иметь возможность назначать курьеров и отслеживать состояние доставки.



### **Проблема и цель**



**Проблема:** Заказы, клиенты, адреса, курьеры и статусы доставки учитываются разрозненно, без единой системы. 
Оператор назначает курьеров и отслеживает доставку вручную, что приводит к ошибкам, задержкам и потере контроля.



**Цель:** разработать информационную систему для централизованной регистрации, обработки и контроля заказов, назначения курьеров и отслеживания статусов доставки.



**Область применения:** система предназначена для использования в службе доставки организации для регистрации заказов, назначения курьеров и отслеживания статусов доставки.



### **Объекты предметной области**



* Служба доставки

  * Заказ

    * Клиент 
    * Адрес
    * Курьер 
    * Статус





### **Роли и пользователи**



|**Роль**|**Назначение**|**Основные действия**|
|-|-|-|
|Клиент|Оформление заказов и отслеживание их доставки|Регистрация и вход в систему; создание и оформление заказа; указание адреса доставки; просмотр истории своих заказов; отслеживание текущего статуса доставки; редактирование личных данных; отмена заказа; оставление отзыва|
|Курьер|Выполнение доставки и обновление информации о заказе|Просмотр назначенных заказов; просмотр адреса и контактов клиента; изменение статуса заказа|
|Администратор|Управление системой, контроль операторов|Создание и блокировка учётных записей; назначение ролей; просмотр отчётов и статистики; настройка параметров системы|
|Оператор|Обработка заказов, назначение курьеров и контроль доставки|Регистрация новых заказов; редактирование данных клиентов и адресов; назначение курьера на заказ; изменение статуса заказа; просмотр списка всех заказов и их состояний; отмена заказа|







### **Функциональные требования**



**Система должна позволять:**



* Создавать заказы
* Редактировать заказы
* Удалять заказы
* Регистрировать клиентов
* Редактировать данные клиентов
* Добавлять адреса доставки
* Редактировать адреса доставки
* Вносить данные новых курьеров в систему
* Редактировать данные курьеров
* Назначать курьеров на заказы
* Устанавливать статусы заказов
* Менять статусы заказов
* Отслеживать состояние доставки
* Добавлять комментарии к заказу
* Управлять пользователями и их ролями
* Генерировать отчёты по заказам и загрузке курьеров







### **Концепция ИС**



**Система:** веб-приложение, доступное через браузер. 


После входа клиенты отслеживают свои заказы, операторы оформляют заказы и назначают курьеров, курьеры отмечают статус доставки, 
руководители смотрят отчёты, администраторы управляют пользователями и системой.



**Основные компоненты:**



* Веб-интерфейс для взаимодействия с пользователями.
* Серверная часть для обработки запросов и управления данными.
* База данных для хранения информации о заказах, клиентах, адресах, курьерах и статусах.
* API для взаимодействия между веб-интерфейсом и серверной частью.



**Результат использования:** сокращение ошибок и задержек, повышение прозрачности доставки, ускорение обработки заказов и улучшение качества обслуживания клиентов
